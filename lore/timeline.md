# Временска линија (за деца)

| Година | Настан |
|---|---|
| 1872 | На 4 февруари во Кукуш е роден Гоце Делчев. |
| 1888 | Учи во гимназија во Солун. |
| 1891 | Заминува на воено училиште во Софија. |
| 1893 | На 23 октомври во Солун е основана Организацијата. |
| 1894 | Гоце е учител во Ново Село кај Штип; се запознава со Даме Груев. |
| 1895/96 | Учител во Банско. |
| 1896 | Со Ѓорче Петров го подготвува Статутот; Солунски конгрес. Станува претставник на Организацијата во Софија. |
| 1903, јануари | Солунскиот конгрес одлучува да се крене востание. Гоце смета дека е прерано. |
| 1903, 4 мај | Гоце загинува кај селото Баница, во Серскиот крај. |
| 1903, 2 август | Почнува Илинденското востание. |
| 1903, август | Крушевската Република трае десет дена. |
| 1946 | Посмртните останки на Гоце се пренесени во дворот на црквата „Св. Спас“ во Скопје. |
