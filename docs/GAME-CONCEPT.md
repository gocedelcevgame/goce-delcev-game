# Game Concept — Патот на Слободата

**Жанр:** образовен ранер за деца (7–12). **Протагонист:** Гоце Делчев; **помошници:** Даме Груев, Јане Сандански, Ѓорче Петров, Пере Тошев.
**Јадро:** 37 фиксни нивоа, секое со историски факт + квиз со објаснување; свитоци/ѕвезди; двоен скок; ритам 7/8 во прелистувач; Suno песна.
**Уникат:** семејно безбедно, без реклами и следење, работи офлајн.

EN: Educational runner for kids 7–12 about Goce Delčev: 37 fixed levels, fact + explained quiz per level, browser-generated 7/8 rhythm, Suno theme song. Family-safe, no ads, offline-capable.
